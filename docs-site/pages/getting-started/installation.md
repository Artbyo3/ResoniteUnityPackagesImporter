# Installation

There are no public installation instructions yet because the importer is still being developed and tested.

!!! warning "Please wait for a release"
    Do not install development builds or copy files from the source repository into Resonite. Development builds may be incomplete or incompatible with your setup.

This page will provide versioned download, installation, and update steps when a public release is ready. Until then, use the [project status](./) and [compatibility notes](../reference/compatibility/) to understand the current development scope.
