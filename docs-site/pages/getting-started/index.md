# Getting started

Install the mod using the [installation guide](installation.md), then follow these steps in Resonite:

1. Start Resonite with ResoniteModLoader and the importer installed.
2. Drag a Unity `.unitypackage` file into Resonite.
3. Follow the import station prompts. For clothing, choose the target avatar when asked.
4. If the importer reports that materials are in a companion package, provide that package when prompted. Otherwise, continue with the available materials.

## What to try first

Start with a small package you are allowed to use and a test avatar. Confirm that the result looks right before using the workflow with important or complex content. Check the [compatibility guide](../reference/compatibility/) if you are unsure whether a feature is supported.
