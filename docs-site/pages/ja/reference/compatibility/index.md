# 互換性情報

互換性は、各 Unity パッケージに含まれるアセット、コンポーネント、マテリアルによって異なります。以下の内容はインポーターの現在の対応範囲をまとめたものであり、特定のパッケージが完全に想定どおりにインポートされることを保証するものではありません。

## ステータス表記について

<div class="status-grid">
  <div class="status-card status-supported"><strong>対応 (Supported)</strong><span>記載されたワークフローや変換が利用可能です。</span></div>
  <div class="status-card status-partial"><strong>一部対応 (Partial)</strong><span>一部のケースや機能に対応していますが、制限があります。</span></div>
  <div class="status-card status-unsupported"><strong>非対応 (Not supported)</strong><span>Resonite 上で同等の挙動への変換は行われません。</span></div>
  <div class="status-card status-planned"><strong>予定 (Planned)</strong><span>今後のアップデートで実装予定の機能です。</span></div>
</div>

## カテゴリ別リファレンス

| 分野 | 概要 |
| --- | --- |
| [Unity パッケージ](unity-packages/) | パッケージの展開、コンテンツの再構築、およびコンパニオンマテリアル |
| [Modular Avatar](modular-avatar/) | 対応する衣装コンポーネントと既知の制限 |
| [VRCFury](vrcfury/) | 現在の機能対応状況 |
| [シェーダーとマテリアル](shaders/) | Standard / PBS、lilToon、および Poiyomi のマテリアル変換仕様 |

オリジナルの Unity プロジェクトやパッケージファイルを信頼できる原本（Source of Truth）として必ず保持してください。インポート結果の外観や挙動は、Unity や VRChat 上での見え方と異なる場合があります。
