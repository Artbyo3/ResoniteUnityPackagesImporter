# Unity パッケージのコンテンツ

**Unity `.unitypackage` ファイル: 対応 (Supported)**。インポーターはパッケージを展開し、対応している Prefab やシーンのコンテンツを Resonite 内に再構築します。

**コンテンツの変換: 一部対応 (Partial)**。メッシュ、Transform、リグ、ブレンドシェイプのデフォルト値、および対応するマテリアル情報が処理されます。対応範囲は各パッケージが使用しているデータ構造やコンポーネントに依存します。

**コンパニオンマテリアルパッケージ: 対応 (Supported)**。マテリアルが別の Unity パッケージに分割されている場合、インポーターはインポート中に追加のコンパニオンパッケージを要求できます。

## メッシュとネストされた Prefab の欠落

- インポート済みモデル内の存在しないメッシュを参照するレンダラーは、警告とともにスキップされます。所有するオブジェクトは保持されます。
- 未対応のネストされた通常の Prefab は、そのソースと依存する Prefab にメッシュがないことを確認できた場合にのみ処理を延期できます。その内容は展開されず、関連する操作も実行されません。
- シーン内の Prefab インスタンスが参照するソースアセットがパッケージに含まれていない場合は、警告とともにスキップされます。

これらの警告は一部対応として表示され、それだけでアバター生成が妨げられることはありません。実際の再構築エラー、モデルファイルの欠落、メッシュを含む、またはメッシュの有無を確認できない未対応のネストされた Prefab は、引き続き生成をブロックします。

## パッケージを検証する前に

必要なマテリアルが同一パッケージ内に含まれているか、別途提供されているかを確認してください。マテリアルが分割されている場合、インポーターはインポート時に [コンパニオンパッケージ](../../importing/companion-packages/) を要求できます。

アバターの生成や衣装の着せ替えは、Resonite 独自のワークフローで行われます。コンポーネントフレームワークやシェーダーごとの詳細な互換性については、各リファレンスページを参照してください。

オリジナルの Unity プロジェクトやパッケージファイルを信頼できる原本として保管してください。インポート結果は Unity や VRChat と異なる場合があります。
