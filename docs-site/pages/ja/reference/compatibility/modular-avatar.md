# Modular Avatar

**全体ステータス: 一部対応 (Partial)**。インポーターは、Modular Avatar の一部の主要な動作を処理します。ビルド時に実行されるその他のコンポーネントについては、Resonite 上でその挙動を再現することなく基底アセットのみがインポートされる場合があります。

## 対応コンポーネント

### Merge Armature

衣装側のボーンを、ターゲットアバターの対応するボーン構造にマッピング・統合します。一致しない独自のボーンは衣装側に保持されます。

### Bone Proxy

衣装オブジェクトを、ターゲットアバターの指定されたヒューマノイドボーンまたはアバターパスにアタッチします。設定されたアタッチ位置やスケール設定はインストール時に適用されます。

## 非対応コンポーネント

- Shape Changer
- 完全な Expression Menu（表情メニュー）の自動インストール
- その他多くのビルド時コンポーネント
