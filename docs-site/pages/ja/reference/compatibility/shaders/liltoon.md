# lilToon

**ステータス: 一部対応 (Partial)**。インポーターは、lilToon のマテリアルプロパティのうち対応しているサブセットを Resonite のマテリアルへと変換します。変換結果は視覚的な近似であり、Unity のシェーダーを完全にそのまま再現するものではありません。

高度な機能やアニメーションを伴う lilToon 機能は変換されない場合があります。パッケージ内にマテリアルデータ自体が含まれていない場合、インポーターは [コンパニオンパッケージ](../../../importing/companion-packages/) を要求することがあります。

対応する静的な第 1 レイヤーの Emission マップおよびブレンドマスクは、Poiyomi と共通のテクスチャ合成ベイカー（Texture-composition baker）を使用して処理されます。lilToon のマスクは RGB とアルファを乗算しますが、変換処理はその挙動を忠実に維持し、メインテクスチャの Transform をマスク座標系に正しく反映します。不足している複合テクスチャ入力は、分割されたコンパニオンインポート間でも復元可能です。

各入力テクスチャは、表現可能な共通の UV セットおよび Transform を共有している必要があります。アニメーションするテクスチャ座標、グラデーション、点滅、視差（パララックス）、加算以外のブレンドモード、完全にシェーディングされたベースカラーとブレンドされる Emission、互換性のないラッピングモード、および HDR 入力テクスチャは、この静的パスでは処理されません。そのような Emission 効果は、マスクなしで誤って発光するのを防ぐため、警告を出力した上で安全に無効化されます。制限事項や非対応のシェーダー機能はアイテムの統合インポートステータスに記録され、ステーションのタブレット UI に表示されるとともに、アバター生成を妨げることなくゲーム内インポートレシートに保存されます。追加の Emission レイヤーやその他のシェーダーマスクは、現時点では一部対応または非対応のままとなります。
