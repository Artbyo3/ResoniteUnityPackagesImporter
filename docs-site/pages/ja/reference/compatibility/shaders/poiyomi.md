# Poiyomi

**ステータス: 一部対応 (Partial)**。Poiyomi マテリアルは、[公式 Unity SDK の Poiyomi コンバーター](https://github.com/Yellow-Dog-Man/Resonite.UnitySDK/tree/809f86046a1d49ed44f30a80c89d67062fee5473/Assets/ResoniteSDK/MaterialConverters/Custom/Poiyomi) から適応されたルールを用いて Resonite ネイティブマテリアルに変換されます。Poiyomi シェーダープログラム自体が Resonite 内で動作するわけではありません。

Automatic（自動判別）パスでは、SDK の挙動に準拠し、トゥーンライティングには Xiexe Toon を、ラップライティング、写実的表現、布地、SDF ライティングには PBS Metallic を選択します。シェーディングが無効化されている場合はトゥーンパスが選択されます。マテリアルエディタで明示的に Toon に上書きした場合、Poiyomi のプロパティマッピングを維持しながら Xiexe を強制選択します。

対応するマッピングには、ベースカラーとテクスチャ、ノーマルマップ、Emission、ブレンドモード、メタリックテクスチャのチャンネル選択および反転が含まれます。また、トゥーンパスでは UV 選択、リムライト、アウトライン、MatCap、オクルージョン、サブサーフェス（SSS）設定、テクスチャ、マルチレイヤー、シェードマップ、スキンシャドウのグラデーション（Shadow ramp）をマッピングします。PBS パスでは詳細テクスチャ（Detail texture）をマッピングし、ハイトディスプレイスメントを近似します。

静的な Emission マップとマスクは共通のテクスチャ合成ベイカーを使用します。Poiyomi のマスクは選択された RGBA チャンネルと反転設定を維持します。Emission マップが存在せずマスクのみが設定されている場合でも発光領域は適切に制限され、単色白に置き換わることはありません。欠落したテクスチャはコンパニオンパッケージによる復元に参加し、必要な合成テクスチャが生成できるまで Emission は安全に無効化されます。

このパスは、同一の UV セットおよび Scale / Offset を持ち、Repeat または Clamp ラッピングを使用する通常の LDR テクスチャをサポートします。サンプリング時にはソーステクスチャの色空間（sRGB / Linear）とアルファ設定を尊重します。異なる UV 座標系・Transform、異なるラッピングモード、プロシージャル生成座標、アニメーションするマスク座標、グローバルマスクのブレンド、ベースカラー依存の Emission、HDR テクスチャ入力は将来の課題です。サポート外の組み合わせはログに警告を出力し、該当する Emission 効果を無効化します。PBS Emission はさらに Albedo の UV0 Transform を必要とします。その他のマテリアル機能は通常どおり利用可能です。

変換は近似的なものです。PBS パスではアウトラインや MatCap などのトゥーン固有効果は失われます。また、アニメーションするシェーダー効果、Dissolve（消滅効果）、AudioLink、追加の Emission レイヤー、完全な色調補正、任意の頂点変形は再現されません。検出された制限事項や近似機能はアイテムの統合インポートステータスに報告され、ステーションのタブレット UI に表示され、アバター生成を阻害することなくゲーム内インポートレシートに保存されます。テクスチャおよび UV の挙動は、変換先となる Resonite マテリアル本来の機能範囲に制約されます。

ロックされたシェーダー（Locked shaders）は、シェーダー名または保持されているマテリアル設定から Poiyomi として識別されます。これらの識別子や必要な値が除去された極度に最適化されたパッケージは自動復元できません。パッケージファイルには通常 Unity プロジェクトの色空間設定が含まれないため、自動／HDR カラーはリニア色空間のプロジェクトとして解釈し、欠落したシェーダーデフォルト値にはドキュメント化されたコンバーターのフォールバックを使用します。不足しているテクスチャはコンパニオンパッケージによる復元が可能です。

パックされたメタリックチャンネルは生の数値データとして並べ替えられます。シャドウランプの着色は SDK のリニアライト計算に準拠します。また、幅ゼロのシャドウ境界や無効なサブサーフェススプレッドに対する有限値ガード処理（数値安定性対策）が組み込まれています。
