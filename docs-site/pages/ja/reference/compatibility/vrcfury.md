# VRCFury

**ステータス: 一部対応 (Partial)**。インポーターは、インポート処理中に VRCFury の構造的なボーン統合機能を共通のアバター処理に変換します。その他の VRCFury 機能は保留または非対応となっており、基底アセットはそれらの挙動を伴わずにインポートされます。

### 対応機能

- **ボーンリンク (`VRCFuryArmatureLink`):**
  - **再帰的マージ (Recursive merge):** 構造的なボーンマージ処理（`ArmatureMergeOperation`）に変換され、ターゲットボーンやオフセットの解決、Transform のリンク（位置、回転、スケール、自動スケール）を保持します。
  - **単一ボーンアタッチ (Single bone attachment):** ボーンアタッチ処理（`BoneAttachmentOperation`）に変換され、ボーンターゲットとオフセットパスを維持します。

### 保留 / 非対応の機能

- **非構造的機能:** トグル、ブレンドシェイプドライバー、プロップ、メニュー、コンタクトレシーバー、アニメーションコントローラーは現時点では実行されません。これらが検出された場合、インポートプランに診断警告が記録され、メッシュ、マテリアル、テクスチャはそれらの動的挙動なしでインポートされます。
