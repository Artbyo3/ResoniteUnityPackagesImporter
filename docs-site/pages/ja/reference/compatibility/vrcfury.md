# VRCFury

**対応する Armature Link 操作、独立した衣装切り替え、継続的なブレンドシェイプ同期を変換します。複雑なコントローラーやコンタクトは再現しません。** コンポーネントがあるだけでは全機能への対応を意味しません。

対応するアーマチュア結合と単一ボーンへの取り付けでは、対象ボーン、オフセットパス、変換オプションを保持します。独立した二値の衣装切り替えは、元の基準状態へ戻す処理を含めて変換します。対象は `Toggle` と対応する `BlendShapeAction`、`MaterialAction`（v1 の `renderer` と v0 の `obj`）、`AnimationClipAction` です。すべてのクリップや動的アニメーションの再生を意味するものではありません。

`BlendShapeLink` の継続的な同期にはネイティブの `ValueCopy<float>` を使用します。任意の `FullController`、多層ステートマシン、コンタクトやハプティクス、セッションをまたぐ状態保存は変換されません。

VRCFury は1つのシリアライズされたコンポーネントに複数の機能を保存します。Armature Link への対応をパッケージ全体への対応と混同しないでください。ソース確認や自動テストは、実機での外観や動作の確認とは別です。
