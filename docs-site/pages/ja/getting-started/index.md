# はじめに

Unity Package Importer は、Unity の `.unitypackage` ファイルに含まれる対応ヒューマノイドアバター、衣装、小物、マテリアルを Resonite へ直接インポートできるようにする Resonite 向け Mod です。

!!! info "現在もアクティブに開発中"
    インポーターは現在も積極的に開発・改善が続けられています。Unity パッケージには多種多様なカスタムシェーダーやエディタ拡張スクリプトが使われているため、変換結果はパッケージの構造によって異なります。対応コンポーネントや既知の制限事項については、[互換性リファレンス](../reference/compatibility/) をご確認ください。

## 各種ガイド

- **[インストール手順](installation.md)**: 前提要件、ResoniteModLoader を用いたセットアップ、アップデート方法、および設定オプション。
- **[アバターのインポート](../importing/avatars.md)**: ドラッグ＆ドロップによる取り込み、対話型インポートステーション、3D ターンテーブルプレビュー、マテリアルカスタマイザー、ネイティブアバター生成。
- **[衣装のインポート（着せ替え）](../importing/clothing.md)**: Modular Avatar および VRCFury による衣装セットアップ、対象アバターの選択、コンテキストメニューのトグル生成。
- **[コンパニオンパッケージ](../importing/companion-packages.md)**: 分割配布されたテクスチャやマテリアルを解決するためのマルチパッケージワークフロー。
- **[互換性リファレンス](../reference/compatibility/)**: Unity パッケージ、Modular Avatar、VRCFury、およびシェーダー変換（Standard / PBS、lilToon、Poiyomi）の詳細な対応状況。
