# アバターのインポート

本インポーターは、Unity パッケージからヒューマノイドアバターを再構築し、ワールドへ正式に取り出す前に対話型ステーションで確認・調整できるようにします。

## インポート手順

1. **パッケージの取り込み**: `.unitypackage` ファイルを Resonite のウィンドウへドラッグ＆ドロップします。インポート前の確認モーダルが表示され、パッケージ名やファイルサイズとともに 3 つの選択肢が提示されます：
    - **Import Unity Package**: 対話型インポートステーションを起動し、アバターや Prefab の再構築、確認、設定を行います。
    - **Import as Raw File**: ステーションを経由せず、Resonite の標準ファイルインポーターと同様に生ファイルとして直接インポートします。
    - **Cancel**: 展開やインポートを行わずに処理を中止します。

    <figure markdown="span">
      ![インポート前の確認モーダル](../images/pre-import-prompt.png){ width="480" }
      <figcaption>Unity パッケージを Resonite にドロップした際に表示されるインポート前確認ダイアログ。</figcaption>
    </figure>

2. **ステーションでのステージング**: ステーションでのインポートを選択すると、パッケージが専用キャッシュに展開され検証されます。ステージングされた Prefab が検査可能な状態で準備されます。
3. **確認とカスタマイズ**: ステーションのタブレット端末に、検出された各アバターや Prefab が表示されます：
    - **3D ターンテーブルプレビュー**: プレビュー台座のスライダーを操作して、アバターを 360° 自由に回転させながら外観を確認できます。
    - **マテリアルカスタマイザー (Material Customizer)**: マテリアルカスタマイザーを開き、メッシュレンダラーや各マテリアルスロットの確認、サムネイル球体の表示、名前によるマテリアル検索、パンくずリストを使ったパッケージ内フォルダの直接参照が可能です。
    - **シェーダープリセット (Shader Presets)**: **Automatic**（シェーダーやプロパティに応じて Xiexe Toon または PBS Metallic を自動判別）、**Toon**（Xiexe Toon を明示的に指定）、**PBS Metallic** を切り替えられます。
    - **ステータス診断**: アイテムのリアルタイムな互換性状態（Ready、Partial compatibility、Blocked）や、詳細なマテリアル警告を確認できます。
4. **アバターの生成**: **Create avatar** を選択すると、モデルがステージングからワールドへと移行し、完全なアバター機能がセットアップされます：
    - ヒューマノイド用の **BipedRig** および **VRIK** 参照を設定。
    - 手の左右（Chirality）やボーンのアライメントをキャリブレーション。
    - 設定されたヘッドセット視点（Viewpoint）を解決してアタッチ。
    - アイトラッキング（まばたき、ウインク、視線追従）を設定。
    - 表情メニューやパラメータートグル用のコンテキストメニューコントロールを生成。
    - ネイティブのアバター保護（設定されている場合）を適用。
    - パッケージの出所、割り当てられたシェーダー、視覚的近似の警告を記録したゲーム内レシート（Receipt）を添付。

!!! warning "ステージング階層はワールド内オブジェクトです"
    インポート処理の実行中、ステージングされたオブジェクトはワールド内の非アクティブなグローバル階層下に配置されます。非アクティブなステージングは完全なローカル専用サンドボックスではないため、セッション内にいる他のユーザーからワールド状態の変化が確認できる場合があります。プライベートなアセットや公開前のモデルをインポートする場合は、プライベートセッションまたはローカルセッションで実行してください。

## マテリアルとシェーダーの処理

- **シェーダープリセット**: 各アイテムはデフォルトで **Automatic** 変換が適用されます。手動で **Toon** または **PBS** に上書きすることも可能です。
- **アイテムレベルの制限警告**: サポート外のブレンドモード、動的な UV スクロール、未ベイクの lilToon レイヤー、2 枚目の Emission マップなどの視覚的近似は、非ブロッキングの制限事項（`IsPartial = true`）として記録されます。アバターの骨組みや構造は正常に維持され、通常どおりアバターとして生成できます。
- **ゲーム内レシート**: アバタースロットには、パッケージの提供元、割り当てられたマテリアル、視覚的制限事項の詳細を記録した永続的なレシートが添付されます。

### マテリアルカスタマイザーの操作

ステーションのマテリアルカスタマイザーでは、検出されたすべてのメッシュに対してマテリアルやテクスチャを詳細に検査・上書きするためのツールが用意されています：

<div class="grid cards" markdown>

-   **メッシュとスロットの一覧**

    ---

    ![マテリアルカスタマイザーのメッシュ一覧](../images/material-customizer-meshes.png)

    検出されたすべての SkinnedMeshRenderer を確認し、サブメッシュスロット数を把握したり、検索フィルターを使って特定のパーツを素早く絞り込めます。

-   **プレビュー球体ピッカー**

    ---

    ![マテリアルプレビュー球体の選択](../images/material-customizer-spheres.png)

    リアルな陰影や反射をレンダリングするプレビュー球体を通じて各マテリアルの質感を視覚的に確認し、適用前にバリエーションを選択できます。

-   **パッケージ内フォルダナビゲーション**

    ---

    ![マテリアルカスタマイザーのフォルダ参照](../images/material-customizer-folders.png)

    展開されたパッケージ内のテクスチャやマテリアルフォルダをブラウズし、別色や別パターンの代替アセットを直接選択・割り当てできます。

</div>
