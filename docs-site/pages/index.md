## What it is

The Unity Package Importer is a ResoniteModLoader mod for bringing supported content from Unity `.unitypackage` files into Resonite. Its in-world station guides you through reviewing avatar and clothing options before you create an avatar or install clothing on a target avatar.

## Compatibility

Support varies by package and feature. The [compatibility guide](reference/compatibility/) is the single up-to-date list of what works and what does not.
