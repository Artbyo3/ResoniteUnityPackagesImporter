# Troubleshooting

There are no public builds available, so this page does not yet contain end-user repair steps. When a release is ready, troubleshooting will be organized around the importer’s version and the stage where an issue occurs.

## While the project is in development

- Do not use development builds as a workaround for an import issue; they are not supported for general use.
- Keep the original Unity project and package files available. Imported content can differ from its source.
- Check the [compatibility notes](compatibility/) for known framework and material limitations.

Release-specific diagnostics and support guidance will be added here before public installation instructions are published.
