# Modular Avatar

**Selected structure and initial appearance transfer. Live menus and reactive behavior do not.** A component being present in a package does not mean its full Unity build process runs in Resonite.

Merge Armature and Bone Proxy translate supported structural operations. Initial blendshape links, supported Shape Changer Set operations, object visibility and material assignments can also be evaluated. These are starting values, not interactive controls; deletion, ambiguous references and unsupported reactive contexts are not silently substituted.
